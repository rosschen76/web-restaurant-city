# 像素餐廳城 Pixel Restaurant City

網頁版、像素風的餐廳經營遊戲，靈感來自早期 Facebook 上的 *Restaurant City*。
擺設家具、雇用員工、學習菜色，把一間小小的台式小吃店經營成傳說中的名店。

**純靜態、零相依、不需要建置**：所有像素美術（家具、人物、菜色圖示、牆壁地板）都由程式即時繪製，音效用 WebAudio 合成，沒有任何圖檔或音檔。

## 開始玩

- **線上**：推到 GitHub 後啟用 Pages（見下方「部署到 GitHub Pages」）
- **本機**：直接用瀏覽器打開 `index.html` 即可；或執行 `npm start`，開啟 <http://localhost:8080>

## 玩法

| 想做的事 | 怎麼做 |
| --- | --- |
| 賺錢 | 客人吃完，**頭上會出現金幣**，店掌櫃會走到他面前用電子支付收款（只有他能收）；**收完款客人才會離開、座位才會空出來**。等越久小費越少，點那位客人可以請掌櫃優先處理；買了「收銀機」，客人會自己結帳 |
| 擴充座位 | 到「商店」買桌椅。**椅子必須緊鄰桌子**，客人才會入座 |
| 應付團體客 | 客人會 1～4 人成組上門，**不同組不共用桌子**。1～2 人優先坐 2 人桌，2 人桌滿了也會替 3～4 人留住大桌；3～4 人找不到夠大的單張空桌時，會**併用兩張相鄰（約 4 格內）的空桌**，不會店裡有位子還在門外乾等。真的沒位子才在門外候位（上限 6 人、耐心 60 秒），多放幾張大桌或長桌吧 |
| 加快出餐 | 多買爐灶（員工煮菜需要空爐灶）、雇用更多員工、升級爐灶種類 |
| 賺更多 | 在「菜單 → 學習」學新菜色（共 **100 道**，分 10 類，Lv.1～48 陸續解鎖）；同一道菜做越多熟練度越高（最高 6 級「大師」：售價 +8%、烹飪 −5% 時間 / 級） |
| 排菜單 | 「菜單 → 菜單」：每間店從學會的菜裡挑**最多 20 道**上架，各店各自設定。客人只點上架、有庫存、而且爐灶煮得動的菜 |
| 爐灶等級 | 每道菜要有**等級夠的爐灶**才煮得動（瓦斯爐 → 快炒爐 Lv4 → 蒸籠灶 Lv8 → 專業爐台 Lv13，高級的可以煮低級的菜）；沒有就賣不了，菜單上會標紅色警告 |
| 單人套餐 | 客人點一道**主餐**，有 50% 機率再加一道**附餐**（湯、飲料、小吃、甜點），視為同一張單：一次煮完（烹飪時間 = 兩道加總 × 0.75）、一次上桌、一次結帳。只有少數客人（約 18%）單點一道湯／飲料／小吃／甜點；菜單上沒有主餐就一律單點 |
| 搭配分數 | 每組「主餐＋附餐」有 −2～+2 的搭配分數：**絕配 ×1.25 價格、1.6 倍小費；好搭配 ×1.12；普通 ×1；不太搭 ×0.9；地雷 ×0.8、0.4 倍小費**，也決定客人從你的菜單挑哪道附餐（好搭配的更常被點）。規則：重口配清爽／冰涼解膩、炸物配冰涼、辣配甜涼、辣配辣／重口配重口／太甜扣分、菜系一致加分、中西不搭扣分，再加上 26 組經典配對（牛排配玉米濃湯、蛋餅配豆漿…）與 16 組地雷（肉燥飯配蛋糕、麻辣鍋配酸辣湯…）。「菜單」分頁會列出目前菜單的好搭配與地雷組合 |
| 單品漲價 | 熟練度 2 級起可以替單品漲價（每間店各自設定）：上限 2 級 1%、3 級 2% … 6 級 5%。上架品項的**漲價合計越多，來客率越低**（20 道全漲 5% 合計 100%，來客率 −10%），所以少數幾道小漲有賺頭，全部都漲得不償失 |
| 進貨與成本 | 「菜單 → 進貨」：每道菜有**食材成本**（約售價的 3 成）。每天 **10:00 固定到貨**，依「每日進貨量」進貨並付錢；食材不會過期、**賣完為止**，全部賣完客人就不上門。倉庫容量 = 40 + 冰箱（小冰箱 +50、雙門冷藏櫃 +140、專業冷凍庫 +320），超過容量的部分不進貨。金幣不夠就買得起多少進多少；完全沒貨又沒錢時供應商會賒帳補 20 份最便宜的菜，不會卡死 |
| 成就 | 「菜單 → 成就」共 33 項：蒐集（學會 10／25／50／75／100 道）、類別大全與精通（精通該類售價 +5%）、單品（同一道菜烹飪 100／500／2000 次）、大師（1／5／20／50 道達 6 級）、**百味宗師**（100 道全大師：全部售價 +10%、烹飪 −5% 時間）。達成發獎金，全公司共用 |
| 吸引客人 | 擺放裝飾、換地板和牆壁，提升「魅力」與餐廳星級（仿米其林，最高**三星**：一星值得一訪、二星值得繞道前往、三星值得專程前往），客人更多、售價更高 |
| 搬家具 | 「裝潢」模式：**視角會切成上視圖（俯視）**，格子是正方形，方便對齊桌椅；點選家具後可旋轉／移動／收起／賣出，也可以直接拖曳。離開後回到原本的等角視角 |
| 擴建 | 「商店 → 擴建」：8×8 → 10×10 → 12×12 → 14×14（Lv12）→ 16×16（Lv22）→ 18×18（Lv32） |
| 找人手 | 「員工 → 招聘」：看應徵者的能力與日薪，雇用後每天午夜發薪 |
| 排班與營業時間 | 「員工 → 排班」：自訂開店／打烊時間、每位員工幾點上班，或交給自動排班 |
| 洗碗 | 買「洗碗槽」。收桌子的人把髒餐具送到洗碗槽，有人洗乾淨才有盤子能用 |

- **店掌櫃就是你**：開局就有、可以命名、不能開除，什麼都會做（點餐、煮菜、上菜、收桌子），而且不會累；**結帳只有他能做**，而且優先於其他工作（煮到一半或正在上菜時不打斷）。如果他一直忙不過來，客人等 45 秒會自助結帳（沒有小費）
- **客流對齊人手**：客人上門的速度依「這個等級的員工名額上限」校準（員工名額 Lv18 達 8 位，Lv21／24／27／30 再各 +1 到 12 位，Lv33／36／39／42 再各 +1，最多 16 位），魅力越高客人越多。店家**依出餐能力安排入座**：同時照顧的客人超過在班員工的能力時，新來的組留在門外候位，不會坐在位子上乾等到生氣——所以座位買得比人手多不會更好（約 2 個座位／位員工就夠），多出來的位子與裝飾是為了魅力
- **環境加成**：魅力（裝飾、桌椅、地板牆壁）越高，客人越有耐心（最多 +30%）、小費越多（最多 +50%）
- **尖峰與離峰**：客人上門的頻率依時段變化——午餐（12–14 點）、晚餐（18–20 點）是尖峰，下午與深夜是離峰。尖峰時客人比較有耐心排隊，客滿走掉的風評扣分也減半；「排班」頁有客流圖，自動排班會把多出來的人手排進尖峰
- **日與夜**：遊戲有天數與時鐘（營業中約 25 秒＝遊戲 1 小時，打烊後沒事做會快轉）。你可以自訂**營業時間與休息時間**，休息時間客人不會上門；夜裡畫面會變暗
- **自動排班**：掌櫃排開店班、值班店長（沒有就等級最高的員工）排收店班；**等級高的員工（Lv.5 以上）優先補尖峰**，**等級低的分成 2～3 個時段錯開上班**，不全部擠在同一個鐘點。員工等級最高 Lv.15（每升一級技術 +0.03、速度 +0.02），Lv.10 起可任命值班店長
- **友善職場**：包含店掌櫃在內，**每位員工每天最多上班 8 小時**（硬性規定，時間到就下班）。可以自己排班，也可以開「自動排班」讓遊戲把班錯開、蓋滿營業時間。**員工離開崗位休息滿 2 小時，體力自動恢復**
- **招聘與日薪**：「員工」面板分成「員工」「招聘」「排班」三個分頁。雇用**不用先付錢**，改成每天午夜發**日薪**（只看員工本身：入職時**能力越強、資歷（等級）越高越貴**，和第幾個被雇用無關——Lv5 約為新人的 2.8 倍、Lv10 約 7 倍、Lv15 約 14 倍；店掌櫃不領薪水）；手上要有至少一天的薪水才能雇。金幣不夠發的員工會累積欠薪，**連續 3 天領不到薪水就辭職**
- **員工福利與士氣**：「員工」分頁最上面可設定兩項（每間店各自設定）：**福利金**（每天午夜提撥薪資總額的 0～20%）與**分紅**（當天扣掉薪水與福利金後盈餘的 0～20%，平分給在職員工）。它們決定員工的**士氣**（0～100）：目標士氣 = 40 + 福利金 %×3 + 分紅 %×1.5，**員工超過 4 位後每多一位再 −3**，領不到薪水的員工也會拉低。士氣每天朝目標靠近 25%；高於 60 速度與技術最多 +7%、低於 60 最多 −10%；**連續 3 天低於 25，就有一位（沒當店長、資歷最淺的）員工離職**。所以員工越多，福利金與分紅就得越高才撐得住，這是擴編的代價
- **加薪**：可替每位員工自訂 0～20% 的加薪：日薪照比例增加，速度與技術也跟著提升（每 1% 加薪 +0.5% 能力，最多 +10%）；調回 0% 能力就恢復，不是永久加成
- **打烊收店**：營業時間一到不再接新客人、門外候位的客人離開。班表剛好結束時，如果店裡還有客人、桌上有餐具或洗碗槽有髒盤子，在班的員工會**留下來收店**：客人吃完、結帳、餐具洗完才下班（最多加班 2 小時）；營業中就到點的班照樣準時下班
- **洗碗槽與盤子**：盤子數量有限（8 個 + 每個座位 2 個）。客人走後桌上的餐具要先收、送到洗碗槽、洗乾淨，沒有乾淨盤子就不能煮菜出餐——洗碗槽與人手都要顧到
- **值班店長**：員工升到 Lv.10 後，可以在「員工」面板任命為**值班店長**，他在班時可以代替掌櫃收款（同一時間只能有一位）。班表上要盡量讓營業時間內都有掌櫃或店長在場
- **風評（−10 ~ +10）**：客人滿意、結帳快會加分，氣走客人、在門外等不到位子離開會扣分；風評高客人上門更勤。**風評連續 15 個遊戲日停在谷底（−10），餐廳就會倒閉、遊戲終止**，只能重新開始
- **暫停**：右上角的暫停鈕（或空白鍵）可以暫停遊戲時間；開著「設定」面板和「裝潢」模式時也會自動暫停
- **遊戲版次**：存檔會記錄遊戲版次（目前是版次 4，可在「設定 → 統計」看到）。載入或匯入存檔時會檢查，**版次差太多（或比目前新）的存檔不會被讀取，只能重新開局**；舊存檔會另外備份在瀏覽器裡
- **分店與總經理**：主店發展到上限（擴建到 18×18、三星）後，可以到 HUD 的「分店」按鈕開設分店（最多 3 間，開店資金 30 萬／60 萬／120 萬）。**開了第一間分店，你就成為總經理**，不再是店掌櫃、也不屬於任何一間店；你可以隨時用上方的店面列檢視任何一間店（調整格局、雇人、排班）。
  - **雙店長制**：每間店（含主店）都有**正店長**（Lv.10 以上，有結帳權限）與**副店長**（Lv.8 以上就能當，但 **Lv.10 以上才有結帳權限**）。開分店時指派一位正店長、一位副店長，派出去之後原本的店也要有夠格的正、副店長；店長缺額每天午夜（與調動、離職時）自動由**綜合能力（速度＋技術）最強**的夠格員工補上。沒有人能結帳的店，客人只能自助結帳（沒有小費）。
  - **公司共用**：金幣、玩家等級、菜單、倉庫、任務；**各店獨立**：格局、員工、風評、魅力、星級、排班。員工可以在店與店之間調動。
  - **懶惰結算**：你沒在檢視的店不會即時運作，**切換店面與每天午夜才補算**（客流約 80%）；營收與日薪直接進公司的金幣，並留下結算報告。
  - **風評與倒閉**：各店風評的平均是**品牌聲譽**，影響每間店的客流。單一分店風評連續 15 天谷底，**那間分店關門**；**所有分店**（至少 2 間）的風評都低於 **−6** 連續 **10 天**，視同主店倒閉、**遊戲終止**；主店自己連續 15 天谷底也是遊戲終止。
  - **主動關閉分店**：家具先放進倉庫（容量 150 件），放不下的按半價賣掉；每位員工可以調回其他店（要有名額）或**資遣**，資遣要加發**資遣費**（日薪的 15 倍）。分店都關了，你回到主店當店掌櫃。
- **完整流程**：客人入座 → 點餐 → 煮菜 → 上菜 → 用餐 → 頭上出現金幣 → 掌櫃結帳 → 客人離開、座位釋放 → 整組都走了，桌上留下餐具 → 有人收拾 → 才能給下一組
- **音效與音樂各有獨立的開關和音量**（右上角兩顆按鈕；設定裡有音量滑桿）。瀏覽器規定要先點擊一下頁面才能出聲
- **裝潢模式會暫停遊戲時間**：慢慢搬家具不怕客人等到生氣
- 員工會自己點餐 → 煮菜 → 上菜；客人整組離席後桌上會留下餐具，**要有人收拾才能讓下一組入座**。員工體力用完會休息，也可以花錢餵食立刻恢復
- **離線收益**：關掉頁面或切到別的分頁時，餐廳照常營業。回來會以 30% 的效率補算（最多 8 小時），並用報告告訴你賺了多少（離線期間掌櫃會照常替客人結帳）
- 客人耐心有限：等太久會氣走；上菜越快，小費越多。偶爾會有 **VIP** 客人（收入與經驗 ×3）
- 右上角可切換 ×1/×2/×3 速度；進度會**自動存檔**在瀏覽器（設定裡可匯出／匯入存檔；存檔文字經過編碼並帶校驗碼，無法手動修改）
- 快捷鍵：`E` 裝潢　`R` 旋轉　`Esc` 取消　`Delete` 收起　`1/2/3` 速度

## 部署到 GitHub Pages

專案是純靜態檔案、全部使用相對路徑，放在 `https://<帳號>.github.io/<repo>/` 這種子路徑下也能正常運作。兩種方式擇一：

**方式 A：GitHub Actions（建議，部署前會先跑測試）**

1. 合併到 `main`
2. 到 repo 的 **Settings → Pages → Build and deployment → Source**，選 **GitHub Actions**
3. 之後每次推到 `main` 會自動跑測試並部署（見 `.github/workflows/pages.yml`），也可在 Actions 頁手動執行

**方式 B：直接由分支部署**

Settings → Pages → Source 選 **Deploy from a branch** → `main` / `/ (root)`。（根目錄已有 `.nojekyll`。）

## 開發

```bash
npm test          # 邏輯層單元／整合／模糊測試（含群體客人、店掌櫃、離線收益、日夜排班、風評、版次）（Node 內建 test runner，零相依）
npm run test:e2e  # 瀏覽器端對端測試（需 Playwright：npm i -D playwright）
npm start         # 本機靜態伺服器
```

```
  art_people.js       人物、菜色圖示、UI 圖示、特效
  render.js           Canvas 繪圖：低解析度緩衝 + 整數倍放大、深度排序、點擊判定
  audio.js            WebAudio 音效與自創 bossa nova 背景音樂（全部即時合成）
  ui.js               HUD、各面板、裝潢模式、輸入
  main.js             啟動、主迴圈、自動存檔
tests/                邏輯測試（sim / fuzz）與端對端測試（e2e）
```

邏輯層（`util / data / world / state / sim`）完全不碰 DOM，所以 Node 就能直接跑測試；繪圖與 UI 只讀取 `Game` 的狀態、並透過它的方法與事件互動。

### 擴充內容

- **新菜色**：在 `js/dishes.js` 加一筆（`ic: '容器:主色配色點綴'` 會用 `art_people.js` 的容器模板程式生成圖示；也可以在 `DISH` 手繪 12×12 的字串像素圖）
- **新家具**：在 `furnitureList` 加一筆，並在 `js/art_world.js` 的 `DRAW` 以等角方塊（`b.box` / `b.cyl` …）畫出來
- **數值平衡**：集中在 `data.js`（價格、解鎖等級、升級曲線）與 `sim.js` 頂端的常數；`tests/sim.test.js` 內有一個自動試玩的經濟測試可以快速檢視節奏

### 關於字型

介面使用系統內建的繁體中文字型。想要像素字型的話，可以自行加入（例如 OFL 授權的 [Cubic 11](https://github.com/ACh-K/Cubic-11)），並在 `css/style.css` 加上 `@font-face { font-family: "Cubic 11"; src: url(...) }`，`--font` 已將它排在字型堆疊最前面。
